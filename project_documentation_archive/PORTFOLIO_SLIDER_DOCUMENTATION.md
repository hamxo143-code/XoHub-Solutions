### Infinite Loop Implementation

The slider uses a **clone-based infinite loop** technique:

1. **Clone Creation**: Clones cards before and after the original set
2. **Position Tracking**: Maintains both `activeSlideIndex` (absolute) and `actualIndex` (real)
3. **Seamless Reset**: Jumps to corresponding real cards when reaching clones
4. **No Animation Reset**: Reset happens instantly without user noticing

```
[Clone 5][Clone 6][Card 1][Card 2][Card 3][Card 4][Card 5][Card 6][Clone 1][Clone 2]
                  ^ Start position (after leading clones)
```

## Event Handling

### Click Events

- **Previous Button**: `slideToPrevious()` + restart autoplay
- **Next Button**: `slideToNext()` + restart autoplay
- **Pagination Dots**: `navigateToPage(index)` + restart autoplay

### Hover Events

- **Mouse Enter**: Pause autoplay
- **Mouse Leave**: Resume autoplay

### Touch Events

```javascript
touchstart → Store swipeStartX, pause autoplay
touchend → Store swipeEndX, process swipe
    → if |distance| > 50px: navigate
    → Resume autoplay after 1s delay
```

### Keyboard Events

- **Arrow Left/Up**: Previous slide
- **Arrow Right/Down**: Next slide

### Window Events

- **Resize**: Debounced recalculation (250ms)
- **Visibility Change**: Pause/resume based on tab state
- **Reduced Motion Change**: Enable/disable autoplay

## Troubleshooting

### Issue: Cards Don't Appear

**Possible Causes:**
1. Portfolio cards missing `.portfolio-card` class
2. JavaScript not loaded (check console)
3. CSS file not linked in `<head>`

**Solution:**
```html
<!-- Verify these are present -->
<link rel="stylesheet" href="assets/css/portfolio-slider.css?v=1" />
<script src="assets/js/portfolio-slider.js?v=1" defer></script>
```

### Issue: Autoplay Not Working

**Possible Causes:**
1. User has `prefers-reduced-motion` enabled
2. Page is in background tab
3. JavaScript error preventing initialization

**Solution:**
- Check browser console for errors
- Verify autoplay timer is set: `XoPortfolioSlider.autoplayTimer`
- Check reduced motion setting in OS

### Issue: Slider Jumps/Resets Visibly

**Possible Causes:**
1. Not enough clones for smooth infinite loop
2. Incorrect index calculation

**Solution:**
- Increase `cloneCount` in `prepareInfiniteLoop()`
- Verify `handleInfiniteLoopReset()` logic

### Issue: Touch Swipe Not Working

**Possible Causes:**
1. Event listeners not attached
2. `{ passive: true }` option missing (prevents default)

**Solution:**
- Verify touchstart/touchend listeners are bound
- Check `processSwipeGesture()` is called
