========================================
PORTFOLIO SLIDER V2.0 - QUICK TEST GUIDE
========================================

BEFORE YOU START:
1. Open index.html in your browser
2. Scroll to the Portfolio section
3. Wait 2 seconds for slider to initialize

========================================
5-MINUTE QUICK TEST
========================================

1. INITIAL LOAD (30 seconds)
   □ Slider appears immediately
   □ 3 cards visible on desktop (or 2/1 on smaller screens)
   □ Navigation arrows visible outside slider
   □ Pagination dots below slider
   □ First dot is active (wider, filled)
   □ No console errors

2. AUTOPLAY (30 seconds)
   □ Wait 4.5 seconds
   □ Slider automatically advances to next slide
   □ Transition is smooth
   □ Pagination updates
   □ Loop continues seamlessly

3. NAVIGATION (1 minute)
   □ Click Next arrow → advances smoothly
   □ Click Previous arrow → goes back smoothly
   □ Click pagination dot → jumps to that page
   □ Active dot updates correctly
   □ Infinite loop works (no blank slides)

4. HOVER TEST (30 seconds)
   □ Hover mouse over slider
   □ Autoplay pauses
   □ Move mouse away
   □ Autoplay resumes

5. RESPONSIVE (1 minute)
   □ Resize to ~1024px → 2 cards visible
   □ Resize to ~480px → 1 card visible
   □ Cards resize smoothly
   □ No horizontal overflow
   □ Navigation still accessible

6. MOBILE (1 minute - if possible)
   □ Open on mobile device or use browser DevTools
   □ Swipe left → advances
   □ Swipe right → goes back
   □ 1 card visible
   □ Everything touchable

========================================
EXPECTED RESULTS
========================================

Desktop (>1024px):
✓ 3 cards visible
✓ Buttons outside slider (-60px offset)
✓ 28px gap between cards

Tablet (768-1024px):
✓ 2 cards visible
✓ Buttons closer (-40px to -8px)
✓ 20-28px gap

Mobile (≤480px):
✓ 1 card visible
✓ Buttons at edges
✓ 16px gap
✓ Swipe gestures work

========================================
COMMON ISSUES & SOLUTIONS
========================================

ISSUE: Cards are too wide or narrow
→ Hard refresh (Ctrl+F5 or Cmd+Shift+R)
→ Check browser zoom is 100%

ISSUE: Slider doesn't advance
→ Check console for errors
→ Verify JavaScript loaded
→ Try refreshing page

ISSUE: Buttons overlap cards
→ Browser may be caching old CSS
→ Hard refresh (Ctrl+F5)
→ Clear browser cache

ISSUE: Pagination doesn't update
→ Check console for errors
→ Refresh page
