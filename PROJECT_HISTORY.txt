Portfolio Slider Visibility:
- NEVER re-enable initPortfolioAnimations() in main.js
- Slider requires cards to be visible immediately on page load
- CSS !important rules in portfolio-slider.css prevent opacity:0 overrides
- forceVisibility() in portfolio-slider.js ensures immediate card visibility

Character Encoding:
- Always save HTML files with UTF-8 encoding
- Use em dash (—) for proper typography, not hyphens
- Avoid copy-paste from Microsoft Word (causes encoding issues)

Icon Usage:
- Use Font Awesome classes consistently: fas, far, fab
- Verify icon names at fontawesome.com before using
- Emojis should be UTF-8 encoded, not HTML entities

Responsive Breakpoints:
- Desktop: >1024px
- Tablet: 768-1024px
- Mobile: 480-768px
- Small Mobile: ≤480px
